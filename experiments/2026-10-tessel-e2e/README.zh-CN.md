# 用拆分后的 skill 让 coding agent 做一个真实功能（2026-10-18）

[English](README.md)

## 问题

之前的实验测的是查找：agent 能不能在 skill 里找到一个事实、读了多少。这次测的是干活本身：给 coding agent 一份很长的团队手册和一个真实任务，skill 能不能让功能做对、并在浏览器里真的能用？把手册拆开（机械拆分或按 holon 规则拆分）后还能不能保持，代价多少？agent 仍然失败时，原因是结构还是文字？

## 设置

- **平台和 skill。** `tessel-frontend` 是为本实验虚构的前端平台，没有模型见过。手册（`skill/v1/full/SKILL.md`，833 行，42,836 字符）模仿真实团队 wiki，里面埋了十条约定 F1–F10：组件位置、`tessel.part` 包装、只用设计 token、CSS layer、所有可见文字走 `t()`、文案文件放在 `locales/<lang>/<name>.strings`、带 `data-ts-dismiss` 和翻译标签的关闭按钮、关闭状态用会话级 `tessel.store` 保存、用 `@tessel/testkit` 写测试、在 `changes/next/` 写变更说明。
- **任务。** 新增一个可关闭的公告横幅组件，提供英文和简体中文，遵守团队约定，写测试，并记录到发布说明。agent 有 `read`、`list`、`write`、`shell` 工具，最多 25 轮。
- **四种给法。** `none`；`full`（整个文件放进系统提示）；`heading`（每个超过 25 行的 `##` 小节移到 `references/`，共 12 个）；`holon`（按 holon 规则用 `holon.py split` 拆分：短核心、一个 `build-parts` 子 skill、10 个 references）。
- **评分。** 静态：十条约定。真实：agent 自己的测试；隐藏的 jsdom 行为测试（两种语言都能渲染、有中文、关闭按钮有标签且能隐藏、重新挂载仍隐藏、新会话重新出现）；esbuild 打包后在 Chromium 中打开并截图，检查点击、刷新、新浏览器上下文。
- **模型。** `deepseek-v4.1-flash` 和 `glm-5.3-flash`，温度 0.3，流式调用并带卡顿看门狗，所有调用、重试和 token 都有记录。因 key 被撤销或限流而中断的运行被排除并计数。
- **skill 版本。** v1 原版；之后每版只改一处：v2 加一条测试规则（用 `renderPart` 返回的 `user`，`await user.click(...)`）；v3 再修掉两句过时的“文案放在组件目录的 `strings.en.json`”；v4 在 holon 的 `build-parts` 子 skill 里加“接下来读这 4 个参考，其余跳过”；v5 列 6 个。

## 结论

1. **skill 决定任务成败。** 没有 skill 时，两个模型做出的东西常常在浏览器里能用，但十条约定几乎都不满足（0.1 和 0.2 分）。有 skill 时三种结构都到 9.4–10 分。
2. **对导航能力强的模型，holon 最好也最省。** deepseek + holon：8 次全满分，自测通过最多，prompt 平均比整文件少 32%（均值 157,537 对 233,227；中位数 129,343 对 164,722）。整文件的成本尾部最长，有运行超过 40 万 prompt tokens。
3. **大部分失败来自文字，不是结构。** 两句过时的话把文案文件指错了位置：deepseek 没上当，glm 在 13 次中有 11 次照做，页面因此没有文字。另外没有任何步骤说明测试里怎么点击，多数 agent 直接点 DOM 元素，触发 React `act` 警告而失败。修好这两处（v3）后，deepseek 三种结构的自测都是 5/5，glm 整文件从 8.0 升到 10.0。
4. **导航弱的模型只做步骤列出的事。** v3 下 glm 用 holon 时最多把 10 个参考文件全翻一遍，平均 21 轮。v4 列 4 个并说“其余跳过”：每次都只读这 4 个，成本降三分之一，但每次都丢掉同样三条约定，因为它们在没列出的两个文件里（8 次全是 7 分）。v5 列全 6 个：8 次全满分，浏览器检查全过，是这个通道上成本最低的条件。
5. **仍未解决。** glm 的自测通过率即使读了规则也偏低（v5 为 3/8），失败在我们的 testkit 替身上，不在功能本身。少数约定满分的页面没显示中文公告，因为横幅文字来自没有默认值的 prop，而任务没说明文字由谁提供。

## holon 的改动

organizer 第 1 步新增：一个步骤要列出它需要的**每一个** `references/` 文件并说明内容，不列不需要的；拆分前先处理互相矛盾的段落，因为拆完后它们会落在不同文件里，读其中一个的人看不到冲突。

## 局限

只有一个虚构 skill 和一个任务；每格 5–10 次，一两次的差别是噪声；两个模型都是 flash 级；testkit 和运行时替身是我们写的；v4/v5 与其他 glm 运行不在同一通道。
